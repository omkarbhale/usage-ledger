# usage-ledger

Where a fleet of coding agents spends its weekly usage: by project, kind of task, agent, account and model.

usage-ledger joins three things that already exist but are never put together: the weekly limits each account reports, the per-session cost and token totals that coding agents write to their own logs, and the record of which task each agent session was doing. The result is a weekly view of which work used which share of each limit, with an estimated API-price cost beside it, and optional per-project budgets that warn when they are overrun.

See [VISION.md](VISION.md) for what it is for and what it will not do.
